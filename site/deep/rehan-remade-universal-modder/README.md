# 异想工坊

直接打开 index.html，无需安装或构建。纯静态、无外部依赖、无运行时联网。

## 产品定位
面向普通玩家的模组创作起点：选择示例游戏 → 描述创意 → 处理像素素材 → 导出素材与制作方案。

## 真实实现
浏览器 Canvas 图片处理：边缘泛洪移除纯色背景、透明区域裁边、最近邻等比例缩放、居中或底部对齐、最近颜色配色映射，以及 PNG 和 Markdown 下载。支持本地 PNG / JPEG 上传，限制 5 MB、2048 像素边长。

## 演示边界
游戏列表和改造路线为演示数据；像素素材为本地绘制预设，场景非游戏截图。创意文本仅用于方案，不生成 AI 素材、代码或可安装模组。没有扫描游戏、安装加载器或实机验证。

## 来源
阅读并参考 README.md、um/scan.py、um/sprite.py。图像处理核心基于 um/sprite.py 的算法改写。上游 MIT License 完整保留于 LICENSE。
