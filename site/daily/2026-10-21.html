让 AI 少写代码的 Ponytail

DietrichGebert/ponytail · 开发者工具MIT⭐ 169,644

👉 打开在线 demo

Ponytail（DietrichGebert/ponytail）是一个给 AI 编程助手用的「懒惰资深工程师」规则集。它让你在 Claude Code 里装一个规则文件，AI 在写代码前会先看两件事：仓库里有没有现成组件，浏览器或标准库有没有原生能力。README 里举的例子很直白：你让它做日期选择器，没有 Ponytail 时它手搓一个日历、塞进 335 行；有 Ponytail 时它把现成的 Input 组件和浏览器原生 date picker 组合在一起，10 行搞定。

它现在火，是因为开发者对 AI 写代码的「啰嗦」越来越不耐烦：功能能跑，但代码量、token 成本和 review 时间都上去了。Ponytail 在 README 里给了一组自测数据（同一 agent 开关技能，39 个任务跑 5 次）：代码量 -53%、耗时 -41%、成本 -26%、token -45%，同时风险逻辑带测试的比例从 68% 升到 98%。这些数字来自作者自己的 benchmark，可信度要自己掂量。

产品化的机会在于把它从「一个提示词文件」变成团队工程纪律工具：成本看板（每个任务花多少 token、复用了多少现有代码）、review 和 audit 命令、把「能不写就不写」的标准固化到团队流程里。这些在 5.x 版本里已经有雏形（band 和 board 都只把数据留在本地）。
