Three ways teams use it

Every run returns numbered screenshots and a prioritized bug list. No test scripts, no device farm to babysit.

🚀

Pre-release sweep

Point a run at your repo before every TestFlight build. Twenty personas hit the flow you care about and file what breaks — while you are still in the branch.

Sample run found: Send button under the Android nav bar, blank deep-link screen, toast covering the FAB.
🌍

Localization & accessibility

iPhone SE in Swedish at 200% text, iPad in Arabic right-to-left, VoiceOver on a Pixel. Catch truncated strings, mirrored arrows and unlabeled icons before review.

Sample run found: untranslated “Receive”, rows clipped at 200%, trash icon with no accessibility label.
🔁

Reproduce & compare

Paste a user report and each phone answers yes, no or unclear with screenshots. Or run the same personas on two builds and get one table of goals, scores and issues.

Sample run found: 7 of 20 phones reproduced the “search clears on rotate” report; 11 could not.
