      Use cases

      Built for people who mod more than one game

      Three situations where a cross-game manager beats five separate mod tools.

      🎮

      Five games, four launchers

      Your library is scattered across Steam, Epic, GOG and itch.io. One scan finds all of it and tells you which engine build each game is actually running — before you install anything.

      🥽

      VR on flatscreen games

      Universal VR injectors need the right engine hooks. Loomkit checks the build, installs the matching injector version, and re-checks it every time the game patches.

      🔄

      Patch day, not panic day

      When a game ships a new engine version, Loomkit flags the mods that might break, snapshots your saves first, and rolls everything back in one click if something crashes.
