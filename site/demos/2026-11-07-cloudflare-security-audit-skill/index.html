Six-phase audits · independently verified findings

AI security audits that show their work.

Paste a repo. Sextant runs the six-phase audit loop — reconnaissance, coverage-led hunting, candidate validation, structured output, independent record verification, then a machine-readable report. Every finding ships with the exact file, line, and the trace of who tried to disprove it.

Audit pipeline

ready

Demo replay is compressed to a few seconds. A real run of the underlying skill takes minutes and writes findings.json, coverage-ledger.json and REPORT.md.

Three verdicts. No vague "possible issues".

Every candidate goes to a fresh verifier whose only job is to disprove it. What survives is classified, and the classification is what you act on — not a confidence score.

Confirmed

Complete source trace + a bounded, observed result.

You get the file, the line, the data flow, and a severity. This is a bug you should fix this sprint.

Needs validation

One exact unresolved fact. No severity assigned.

The auditor tells you precisely what it could not determine, so a human resolves it in minutes instead of re-doing the whole hunt.

Rejected

A disproved candidate, kept on the record.

Recorded so the next run doesn't waste hunters on it — and so the finding count means something.
