How people actually use it

Three workflows that keep showing up in user interviews.

🌙

The night-before sanity check

You're about to double a position before earnings. Run the council first and read the risk officer's paragraph — the bear case arrives before the gap down, not after.

🎬

Content that writes itself

Creators export the full transcript — four openings, two rebuttals, one verdict — and cut a six-minute video from it without writing a script.

📐

Rules before feelings

Set a house ruleset — max 6% per name, never add below the 200-day. The risk officer enforces it inside the verdict, so discipline stops being a mood.
