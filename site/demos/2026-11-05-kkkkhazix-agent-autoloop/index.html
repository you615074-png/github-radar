Same core, different rules. Sources, agents and notification channels are all pluggable — no glue code, no SDK.

🌙

Overnight issue triage

A bug lands at 2am. By 9am there is a patch, a green test run and a PR ready for review. Nobody sat watching a terminal. 

{ "when": { "source": "github", "types": ["issues.opened"] },
  "to": "codex", "cwd": "~/code/billing" }
🚨

Alerts with a human gate

Your error tracker fires. The agent traces the stack and finds the bad deploy — then stops before restarting production, because you said ask first. One tap on your phone and it finishes. 

{ "when": { "source": "http" },
  "ask_first": ["restart", "delete", "deploy"] }
🧹

Sunday cleanup

Every week the loop wakes up, strips dead code, opens a review branch, and logs exactly what it touched and what it cost. You read the summary over coffee. 

{ "when": { "cron": "0 18 * * 0" },
  "to": "claude-code", "cwd": "~/code/app" }
