Four steps, no magic

Everything the model does is visible. That is the whole point.

01

Pick a recipe

64M dense, a 26M small model, or a 198M-A64M MoE — each ships with its own data and hyperparameters.

02

Press start

One click launches the run. Step, loss, throughput and dollars stream into the console as it goes.

03

Watch the curve

Inline notes explain warmup, LR decay, and the exact moment a loss spike turns into a lesson.

04

Talk to it

Run the same prompt against step 0 and step 2,000. The gap between them is the entire story.

Three ways people use it

🔧

Learn by breaking it

Crank the learning rate, kill the run at step 900, watch the curve flatline into noise. Every knob is exposed because nothing is buried under a framework wrapper.

Best for: self-taught engineers

🎓

Teach a class

Share one lab link with 30 students. Same seed, same data, same 20-minute run — then compare loss curves side by side in the instructor dashboard.

Best for: instructors & bootcamps

💼

Interview prep

Answer “why does LoRA freeze the base weights?” from memory — because you trained both variants last night and compared the curves yourself.

Best for: LLM interview candidates
